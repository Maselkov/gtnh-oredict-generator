          How card strings work

          • | is OR, & is AND, and ! in front of a term means "has no ore name like this". They are applied strictly left to right, with no brackets.
          • ingot* starts with, *Copper ends with, *Hot* contains, and a plain name must match exactly.
          • An item matches a term if any one of its ore names does.
          • If the string contains any of \ ^ $ + ( ) [ ], the whole thing is read as one regular expression instead.

          Why extra items show up

          A card only sees ore names. Items with exactly the same ore names, like the same ingot from two mods, can never be told apart, so picking one includes the other. Rarely, an item carries only ore names that your group also uses, and it cannot be excluded either. Both are listed under the group.

          About wildcards

          Wildcards keep strings short, and the page only uses one when it matches nothing outside your group in this version of the pack. A future update could add items that a wildcard catches. Untick "Use wildcards" for a string made only of exact ore names.
